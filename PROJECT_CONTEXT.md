RS MOBILE CORNER — PROJECT CONTEXT

Vision

RS Mobile Corner is not a typical mobile repair website.

The goal is to create a premium, memorable, story-driven digital experience that feels closer to an award-winning agency portfolio than a local repair shop website.

Inspirations:

* Apple
* Awwwards websites
* Locomotive
* Studio Freight
* Resn
* Active Theory
* Linear
* Stripe

The site should feel handcrafted, premium, elegant, cinematic and emotionally human.

⸻

Brand Story

RS Mobile Corner is a mobile repair business operated by Rahim Bhai.

Core philosophy:

“Every phone deserves a second life.”

The website should communicate:

* Trust
* Craftsmanship
* Human connection
* Years of experience
* Honest diagnostics
* Premium repair quality

NOT:

* Cheap repair shop
* Generic service website
* Booking-first experience

The story and emotional connection come first.

⸻

Design Language

Visual Style

* Premium editorial
* Luxury magazine aesthetic
* Soft warm backgrounds
* Glassmorphism only where appropriate
* Large typography
* Generous whitespace
* Elegant animations
* Clean layouts

Colors

Background:

* Warm ivory
* Cream
* Off-white

Accent:

* Soft gold
* Champagne gold

Text:

* Deep charcoal
* Near black

Avoid:

* Bright green
* Neon effects
* Cheap gradients
* Generic UI

⸻

Hero Section

Current direction:

* Large editorial headline
* Portrait of Rahim Bhai
* Floating trust badges
* Signature “Meet Rahim Bhai”

Requirements:

* Signature should remain straight
* Positioned near image bottom
* Never overlap primary content
* Mobile layout must remain clean

⸻

Founder Story Section

Current redesign direction:

Interactive story cards.

Requirements:

* User manually controls cards
* Swipe
* Drag
* Arrow navigation

Avoid:

* Scroll trapping
* Forced storytelling
* Long pinned sections

Cards should:

* Feel tactile
* Feel physical
* Feel collectible

Content should focus on:

* Learning mobile repair through training and experience
* Shop beginnings
* First customers
* Growth journey
* Reputation
* Present day

⸻

Services Section

Current direction needs redesign.

REMOVE:

* Booking UI
* Warranty blocks
* Timers
* Generic service cards
* Corporate service section design

NEW DIRECTION:

Create a floating repair deck.

As user scrolls:

Card 1 rises upward.

At ~30% progress:

Card 2 begins rising.

At ~30% progress:

Card 3 begins rising.

Continue similarly.

Motion:

* Floating
* Rotating
* Layered
* Depth based

Think:

Cards drifting upward through space.

Cards represent:

* Display Repair
* Battery Replacement
* Charging Port Repair
* Camera Repair
* Motherboard Repair
* Software Repair
* Water Damage Recovery

Cards should contain:

* Large bold title
* Strong visual iconography
* Short description

No clutter.

No business dashboard feeling.

Pure visual storytelling.

⸻

Animation Philosophy

Animations should feel:

* Natural
* Physical
* Premium
* Purposeful

Avoid:

* Random motion
* Excessive GSAP tricks
* Motion without meaning

Prefer:

* Framer Motion
* GSAP ScrollTrigger
* Layered depth
* Smooth transforms
* Subtle parallax

⸻

Mobile Experience

Must be designed intentionally.

Not desktop squeezed into mobile.

Each section should have:

* Dedicated mobile behavior
* Touch interactions
* Reduced animation complexity

⸻

Creative Freedom

If a better idea exists than the current implementation:

Improve it.

Do not blindly follow instructions if a more premium solution exists.

Always optimize for:

1. User experience
2. Visual quality
3. Performance
4. Storytelling
5. Brand perception
